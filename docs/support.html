Support

Something wrong? Say so from inside the app.

The fastest way to report a problem is the report built into CULL: open Settings, go to About, and choose Report a problem. It asks what happened and what you expected, and can attach diagnostics that you read before they leave your computer.

What a report contains

  • What you typed.
  • If you tick the box: the app version, your operating system, counts of file types in the shoot, your settings without any path, and the last lines of the log.
  • Never a photograph, a thumbnail, or the name of a file, a folder or a person. Paths are reduced to their file extension before anything is written.

The report is saved as a file on your computer and shown to you. You choose whether to send it.

If CULL will not start

The log is in the app's log folder: on Windows under %APPDATA%\dev.cull.app\logs, on macOS under ~/Library/Logs/dev.cull.app. It contains no file names. Attach cull.log to your message.

Lightroom does not show my verdicts

  • Import the folder with Add, not Copy, so Lightroom reads the sidecars where they are.
  • For a folder already in your catalog, select the photos and choose Metadata → Read Metadata from Files.
  • A DNG carries its verdict inside the file. Lightroom reads it on import, or on Read Metadata from Files.
