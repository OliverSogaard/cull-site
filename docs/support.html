Support

The quickest way to report a problem is from inside the app: Settings, About, Report a problem. Say what happened and what you expected. You can attach diagnostics, and you read them before they go anywhere.

A report never contains a photograph, a thumbnail, or the name of a file, a folder or a person. It is saved on your computer first, and you choose whether to send it.

Early days

CULL is new and free while it grows. If you use it now and tell me what breaks or what is missing, that is remembered: when a paid version arrives, the people who helped shape it keep the full app free for longer than everyone else.

If CULL will not start

The log file is called cull.log. On Windows it is in %APPDATA%\dev.cull.app\logs, on a Mac in ~/Library/Logs/dev.cull.app. It contains no file names. Send it along.

Lightroom does not show the verdicts

  • Import the folder with Add, not Copy, so Lightroom reads the sidecars where they are.
  • If the folder is already in the catalog, select the photos and choose Metadata → Read Metadata from Files.
